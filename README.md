# BuyAnything Android starter

**Important:** Extract this ZIP first. Upload the extracted files and folders into the root of your GitHub repository; do not upload only this ZIP. Keep the hidden `.github/workflows/android.yml` file.

Then open GitHub → Actions → Build BuyAnything Android APK → Run workflow. When successful, download the `BuyAnything-APK` artifact and extract it to get `app-debug.apk`.

Demo features: food list, search, filters, cart, demo checkout. Real login, payment processing, restaurant database, GPS tracking, notifications, and production backend are not connected.
